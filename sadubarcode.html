Proyek / SaduBarcode

Satu sistem untuk barcode, label, dan 996 SKU.

SaduBarcode adalah sistem internal Sari Madu Bakery untuk mengelola katalog produk, barcode, dan label dari satu sumber data—lalu meneruskan alurnya ke pencatatan produksi dan verifikasi distribusi.

Web, Data Sari Madu Bakery 996 SKU Des 2025 - sekarang
Fitur

Yang bisa dilakukan SaduBarcode

Dari memperbarui katalog sampai memastikan jumlah barang yang dikirim, tiap langkah memakai data produk dan barcode yang sama.

Barcode per produk

Buat barcode untuk tiap produk dengan format CODE128, CODE39, EAN-13, atau UPC. Riwayat pembuatan membantu operator menelusuri pekerjaan sebelumnya.

Cetak label massal

Cetak satu produk atau batch besar, termasuk alur pencocokan nama produk dari file ERP dengan katalog utama sebelum label dicetak.

Katalog 996 SKU

Cari dan kelompokkan produk berdasarkan kategori. Data kode, nama, harga, dan masa simpan tersimpan sebagai rujukan operasional.

Dashboard harian

Kelola data produk dan lihat ringkasan katalog dari satu tampilan, tanpa berpindah di antara file spreadsheet yang terpisah.

Impor dan ekspor Excel

Impor katalog dengan pratinjau kolom dan pemeriksaan duplikasi sebelum data disimpan; ekspor katalog kembali ke spreadsheet.

Desain template label

Atur ukuran label dan posisi nama, barcode, harga, serta tanggal. Simpan template untuk menjaga hasil cetak tetap sesuai kebutuhan produk.

Catatan produksi

Susun rencana produksi, catat jumlah hasil baik dan reject, lakukan verifikasi, lalu cetak label sesuai hasil produksi.

Verifikasi distribusi

Pindai barcode melalui kamera ponsel atau scanner untuk mencatat jumlah terkirim, reject, dan selisih terhadap target.

Tim dan terminal cetak

Atur akses anggota, operator ber-PIN, terminal kerja, kalibrasi posisi cetak, serta riwayat aktivitas operator.

Tampilan aplikasi

Fitur yang sama, langsung dari UI SaduBarcode

Screenshot di bawah diambil dari antarmuka aplikasi yang dijalankan secara lokal. Data pada layar merupakan data contoh untuk memperlihatkan alur tiap fitur.

Alur kerja

Dari data produk sampai barang terverifikasi

Impor dan kelola SKU

Masukkan katalog dari Excel, periksa data, lalu kelola produk dan kategori.

Generate barcode

Kode dibuat otomatis mengikuti data SKU yang sudah ada.

Cetak label

Label dicetak massal dalam satu batch, siap ditempel.

Catat dan verifikasi

Rekam hasil produksi, lalu pindai barang untuk memeriksa jumlah distribusi.

Implementasi

Dibangun untuk alur kerja operasional

Aplikasi web full-stack dengan antarmuka React dan TypeScript, API Express, autentikasi pengguna, serta dukungan PWA untuk penggunaan lintas perangkat.

React TypeScript Vite Express PostgreSQL / SQLite PWA
